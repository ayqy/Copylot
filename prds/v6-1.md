# v6-1 Popup 与 Options 用户体验优化

## 范围

- 删除 Popup 的“第一次干净复制”、首次成功复用卡、三步 onboarding、重新打开引导及成功次数解锁提示。
- 将普通复制固定为主动作，Prompt 快捷位作为次级动作；仅在存在追加会话时展示追加状态。
- 将隐私页改为用户信任中心，清楚解释本机处理、Chrome Sync 与可选本地使用记录。
- 将 Pro 页改为“规划中”说明页，不再向用户暴露验证、分发、证据与增长流程。
- 保持现有色彩、字体、控件与 Options 导航习惯，按 `ui` skill maintenance mode 做必要调整。

## 交互验收

- Popup 首屏无需阅读教学即可找到复制动作；失败后窗口保留且给出下一步建议。
- 隐私页在一个屏幕内说明三类数据边界，新安装默认关闭本地使用记录。
- Pro 页明确尚未上线、没有订阅/付费/候补名单，免费能力不受影响。
- 中英文、窄宽度、浅色与深色模式无截断、重叠和横向滚动。

## 完成结果

- Popup 已移除首次复制教学、复用卡和增长门槛；“复制给 AI”固定为首要动作，Prompt、设置与分享等操作保持次级层级。
- Popup 会等待真实复制结果：成功后关闭；失败时保留窗口，显示可恢复原因并把焦点移回主动作。
- 隐私页按“本机处理、Chrome 同步、本地记录”组织，并将可选本地记录默认关闭；关闭时同步清除对应记录。
- Pro 页只呈现尚未上线的产品规划、免费版边界与用户场景，不再加载研发验证、增长或证据工具。
- 中英文、常规/窄宽度、浅色/深色共 10 张运行态截图已逐张复核；修正同步状态对比度、内部化文案和英文 Pro 命名后，无明显截断、横向溢出或层级问题。
